# Как сдать практическую работу №2

## 1. Что уже подготовлено
В архиве находится готовая игра на C#, исходный код, README и Git-репозиторий с историей коммитов. Ветка `main` содержит итоговую версию. Отдельные ветки функций сохранены в репозитории.

## 2. Как открыть и запустить игру
1. Установи **.NET 8 SDK** с официального сайта Microsoft: https://dotnet.microsoft.com/download/dotnet/8.0
2. Распакуй архив.
3. Открой папку `TicTacToe` в Visual Studio или VS Code.
4. Открой терминал в этой папке и введи `dotnet run`.
5. Введи номер клетки от 1 до 9. Игроки X и O ходят по очереди.

Схема поля:

    1 | 2 | 3
   ---+---+---
    4 | 5 | 6
   ---+---+---
    7 | 8 | 9

После окончания партии введи `д`, чтобы сыграть ещё раз, или `н`, чтобы выйти.

## 3. Как загрузить готовый репозиторий в свой GitHub
Я не могу создать репозиторий непосредственно в твоём аккаунте без входа в него. Сделай это сам:
1. Зайди на https://github.com и нажми **New repository**.
2. Назови репозиторий `Prakticheskaya-2-Krestiki-Noliki`. Выбери Public или Private.
3. Не добавляй README, .gitignore или лицензию — они уже есть в проекте.
4. Открой терминал в распакованной папке `Prakticheskaya_2_Krestiki_Noliki` (там, где лежит папка `.git`).
5. Выполни команды, заменив `ТВОЙ_ЛОГИН` на свой логин GitHub:

```bash
git remote add origin https://github.com/ТВОЙ_ЛОГИН/Prakticheskaya-2-Krestiki-Noliki.git
git push -u origin main
git push origin --all
```

Если GitHub попросит авторизацию, войди через браузер или Git Credential Manager.

## 4. Как создать Pull Request
В репозитории на GitHub:
1. Открой вкладку **Pull requests**.
2. Нажми **New pull request**.
3. В поле `base` выбери `main`, а в `compare` — одну из веток: `Inputcorrectness`, `Rules`, `win`, `draw`, `restart`.
4. Нажми **Create pull request**, добавь название, например `Добавлена проверка ввода`, и создай PR.
5. Нажми **Merge pull request**, затем **Confirm merge**.
6. Повтори для остальных веток, если преподаватель требует, чтобы PR были видны именно на GitHub.

Важно: в локальной истории уже есть merge-коммиты, показывающие слияние функций в `main`. Если нужно, чтобы на странице GitHub отображались именно карточки Pull Request, их необходимо создать через сайт — локальная команда Git не может создать PR от имени аккаунта.

## 5. Что показать преподавателю
- Запуск игры командой `dotnet run`.
- Проверку неправильного ввода: например, ввести `0`, `10` или букву.
- Попытку занять клетку, в которой уже стоит X или O.
- Победу по строке, столбцу или диагонали.
- Ничью.
- Повторный запуск партии после завершения.
- Вкладку **Branches** и историю коммитов в GitHub.

## 6. Краткое объяснение кода
- `board` — массив из 9 ячеек игрового поля.
- `currentPlayer` — знак игрока, который сейчас ходит.
- `GetPlayerMove()` проверяет, что введено число от 1 до 9 и клетка свободна.
- `DrawBoard()` выводит поле на экран.
- `HasWinner()` проверяет 8 возможных выигрышных комбинаций.
- `IsDraw()` проверяет, что все клетки заняты.
- `ResetGame()` очищает поле и возвращает первый ход игроку X.
- `PlayGame()` управляет ходами до победы или ничьей.
- `Main()` запускает партии и предлагает сыграть снова.
