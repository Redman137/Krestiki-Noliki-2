# Практическая работа №2 — «Крестики-нолики»
Консольная игра на C# (.NET 8) для двух игроков.

## Возможности
- Ввод только чисел от 1 до 9; запрет занятой клетки.
- Чередование игроков X и O.
- Проверка победы по строкам, столбцам и диагоналям.
- Определение ничьей.
- Повторная игра без перезапуска приложения.

## Запуск
Установить .NET 8 SDK, открыть терминал в этой папке и выполнить `dotnet run`.

## Ветки Git
`Inputcorrectness`, `Rules`, `win`, `draw`, `restart`. Каждая ветка добавляет исходный файл своей функции; ветки слиты в `main` merge-коммитами.
